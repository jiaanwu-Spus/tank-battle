# 坦克大战 (Battle City)

一个纯 HTML + Canvas 实现的经典坦克大战游戏，单文件，无需任何依赖，直接用浏览器打开即可游玩。

## 玩法

- 控制我方坦克，消灭所有敌方坦克，并保护底部的**基地（老鹰）**不被摧毁。
- 击毁砖块 `#` 可开辟通路；钢板 `@` 无法被普通子弹击穿。
- 击毁橙色「奖励坦克」有概率掉落**星星道具**，拾取后可升级火力（子弹可击穿钢板、双发）。
- 每关敌人数量递增，通关后自动进入下一关；第 3 关之后为程序随机生成的关卡。

## 操作

| 按键 | 功能 |
| ---- | ---- |
| `W` `A` `S` `D` / 方向键 | 移动 |
| `空格` / `J` | 射击 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 / 进入下一关 |

## 运行

直接双击打开 `index.html`，或使用任意静态服务器：

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术要点

- Canvas 2D 渲染，`requestAnimationFrame` 游戏主循环（基于 delta time）。
- 基于网格的碰撞检测（坦克 ↔ 墙体 / 坦克 ↔ 坦克 / 子弹 ↔ 墙体·坦克·子弹）。
- 车道对齐（snap）机制，保证转向后移动顺畅。
- WebAudio 合成音效，无需外部音频资源。
